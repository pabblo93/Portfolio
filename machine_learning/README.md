# Machine Learning

Proyectos de aprendizaje automático en Python, cubriendo regresión y clasificación con scikit-learn.

---

## Proyectos

### `customer_purchase_model/`
Pipeline completo de clasificación para predecir el comportamiento de compra de clientes. Incluye análisis exploratorio, preprocesamiento (encoding, escalado) y regresión logística sobre un dataset de 238 clientes de Kaggle.

**Técnicas:** Regresión logística · OneHotEncoding · StandardScaler · Train-Test Split

[Ver proyecto →](customer_purchase_model/)

---

### `regression_project/`
Introducción práctica a la regresión lineal simple con scikit-learn sobre datos sintéticos. Cubre ajuste del modelo, interpretación de coeficientes y visualización de la recta de regresión.

**Técnicas:** Regresión lineal · R² · scikit-learn

[Ver proyecto →](regression_project/)
