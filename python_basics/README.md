n# 🐍 Python Basics

Colección de ejercicios y proyectos iniciales para aprender Python, incluyendo conceptos fundamentales y aplicaciones prácticas.

## 📋 Contenido

### Ejercicios Implementados

| Archivo | Descripción | Tema |
|---------|-------------|------|
| `clase en python.ipynb` | Conceptos básicos del lenguaje | Fundamentos |
| `test de librerias.ipynb` | Pruebas de librerías y funcionalidades | Testing |
| `ejemplo_blockchain.ipynb` | Implementación educativa de blockchain | Criptografía |
| `Ejemplo_Blockchain.py` | Versión en script de blockchain | Criptografía |

## 🎯 Temas Cubiertos

### Fundamentos de Python
- Variables y tipos de datos
- Control de flujo (if, for, while)
- Funciones y módulos
- Manejo de excepciones
- Estructuras de datos (listas, diccionarios, sets)

### Aplicaciones Prácticas
- **Blockchain:** Hash, merkle trees, cadena de bloques
- **Web Scraping:** Descarga y procesamiento de datos web
- **Análisis de Datos:** Pandas, numpy para análisis epidemiológico
- **Algoritmos:** Proof of Work, minería simulada

## 🔧 Instalación

### Requisitos

```bash
pip install -r requirements.txt
```

### Dependencias Principales

- `jupyter` - Para ejecutar notebooks
- `numpy` - Computación numérica
- `pandas` - Análisis de datos
- `requests` - Requests HTTP
- `beautifulsoup4` - Web scraping
- `hashlib` - Funciones hash

## 💡 Proyectos Destacados

### 🔗 Blockchain Simplificado
Implementación educativa de una blockchain con:
- Bloques con hash SHA-256
- Validación de integridad
- Minería con Proof of Work

**Archivos:** `Ejemplo_Blockchain.py`, `ejemplo_blockchain.ipynb`

### 📊 Análisis Serológico
Análisis de datos de pruebas serológicas (COVID-19 presumiblemente):
- IgM e IgG antibodies
- Interpretación de resultados
- Visualización de datos

**Archivos:** `serologias.ipynb`, `serologias.xlsx`

### 🔍 Web Scraping OMIE
Descarga de matriz de precios de producción eléctrica (OMIE):
- Requests HTTP
- Parseo de datos
- Almacenamiento

**Archivos:** `Descarga_Matriz_OMIE_SQ.py`
